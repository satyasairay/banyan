# SOURCES — asset provenance

**The engine, the trees, and every scene are 100% procedural. Zero external
assets are bundled.** Geometry, bark, leaves, ground, grass, litter and light
are all generated by the code in `banyan_v5.source.html`.

| Asset | Source | License |
|---|---|---|
| Tree geometry, bark, leaves, ground, grass, litter | procedural (this repository) | — |
| Scenes and seasons (light rigs, sky gradients, ambience) | procedural (this repository) | — |
| three.js r165 (`vendor/three.module.js`, bundled into the runtime by the build) | https://threejs.org — see `vendor/PROVENANCE.md` | MIT |
| esbuild 0.28.1 (build dependency only, never shipped) | https://esbuild.github.io | MIT |

Notes:

- The gold previews in `gold/*.webp` are captures of this renderer's own
  output — not external artwork.
- All GLSL noise is authored in this repository.
